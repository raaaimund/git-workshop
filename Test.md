## merge conflict

- merge means combining two/multiple branches
- modification happens when merging two branches together / one branch into another
- two commits on separate branches modify the same file **AND at least one same line number in those files**
- merge conflict means conflict when merging two branches which created **changes inside the same file in the same line numbers** where we have to choose one **FINAL/CORRECT** version which sould be used after solving the merge conflict.
